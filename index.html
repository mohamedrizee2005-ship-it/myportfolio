GainTrack Strength

A clearer routine for home workouts.

An Android workout app developed with AI assistance to explore a simple idea for home training. Version 4 includes a four-day plan, push-up difficulty levels, set logging, a rest timer, and weekly progress tracking. It works offline.

  • Kotlin
  • Jetpack Compose
  • Material 3
  • Local storage
Source code Android release
About this AI-assisted project +

The starting point. I wanted a straightforward way to follow a routine and keep track of home workouts.

A deliberate change. With AI assistance, the app was simplified into three sections: Today, Plan, and Progress. Set checkmarks, rest countdowns, and recovery of unfinished sets keep the workout flow focused.

Under the surface. The app uses Kotlin and Jetpack Compose, with local storage for workout settings and checkmarks. AI tools assisted with implementation. This project is part of my exploration while I build my programming foundations.

Version 4 is a workout MVP distributed as a development APK. The image is an illustrative recreation; visual details may differ from the installed app.

HallSync

Lecture hall booking, in one place.

For this group project, we built a booking system with a browser interface and a Java/MySQL backend. Students view halls and schedules, lecturers request rooms, and administrators manage approvals and reports.

  • Java
  • MySQL
  • JDBC
  • Maven
  • HTML / CSS / JS
Source code Setup guide
Inside the group project +

The problem. Manual reservations make availability, timetable conflicts, and booking approvals difficult to track.

The approach. Role-based access separates student, lecturer, and administrator workflows. Java services use JDBC to work with MySQL; validation and coordinated transactions help prevent overlapping approved bookings.

Checking the result. The repository includes automated checks for database rules, application behaviour, browser interactions, and the Windows launcher, alongside installation and upgrade instructions.

A completed university group project designed for local demonstration.
