How I built GainTrack Strength v4 +

The problem: Starting strength training at home can be confusing without a clear routine, realistic progressions or gym equipment. I wanted an easy way to stay consistent and track training progress.

My solution: I designed a four-day equipment-free routine with push-up variations matched to ability, exercise instructions, set checkmarks, a rest countdown, recovery days and a 12-week consistency view. The profile also tracks a simple weight milestone.

How it works: Kotlin, Jetpack Compose and Material 3 power the Android interface. Workout checkmarks and settings are stored locally, with earlier app data preserved for upgrades. GitHub Actions compiles the downloadable Android APK.

What I improved: I simplified the earlier multi-feature app into three focused sections—Today, Plan and Progress—and improved the workout flow with animated feedback, a rest timer and recovery of unfinished sets.

Version 4 is a workout-only Android MVP, not a medically personalized training service or Play Store release. The downloadable APK is a development build. Sufficient food intake and rest are still important for healthy weight and muscle gain.

How our group built HallSync +

The problem: Manual lecture hall reservations make it difficult to check availability, avoid timetable conflicts and track approvals.

Our solution: Role-based access for students, lecturers and administrators; searchable halls and schedules; booking requests and approvals; maintenance closures; and CSV or calendar exports.

How it works: Java services and JDBC connect a responsive HTML/CSS/JavaScript interface to MySQL. Database validation and coordinated transactions prevent overlapping approved bookings.

What we tested: GitHub Actions checks database rules, application behavior, browser interactions and the Windows launcher. The README explains installation, configuration and upgrades.

What I studied: How the ER diagram, MySQL tables, JDBC connection and booking-conflict validation fit together, so I can explain how this group project works. Feature ownership is not assigned to one person here.

HallSync is a completed university software project designed for local demonstration, not a live university-wide booking service.
